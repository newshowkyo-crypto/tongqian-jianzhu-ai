# 11 经营机会雷达 - Requirements

## Introduction

> **5 大杀手锏 之 1**（功能区 A）：项目机会雷达 + 可投性判断 + 业主真假性核验 + 同行雷达 + 推荐报价区间。落地 [`design.md` §5.10 BR-321 Tier 分级](../00-project-overview/design.md)（项目可投性 < ¥1000 万 = T1 / ¥1000–5000 万 = T2 / ≥ ¥5000 万 = T3）。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`20-knowledge-system`]（数据源）；后续被 [`22-agent-workspace`]（机会派单源头）消费。

## Requirements

### Requirement 1：每日机会推送

#### Acceptance Criteria

1. THE 客户在订阅"关注地区 + 业务线 + 金额区间"后，THE Platform SHALL 每天 8:00 推送匹配机会列表（每日上限 5 条，BR-604）
2. THE 推送渠道：站内信 + 公众号 + 桌面通知（[`27-notification-center`]）

### Requirement 2：可投性评分（AI Tier 分级）

#### Acceptance Criteria

1. 输入：项目信息 + 客户企业资质 + 历史业绩
2. 输出：0-100 分 + 4 维分项（资金 / 资质 / 关系 / 业绩）+ 风险点
3. Tier：< ¥1000 万项目 → T1 主动给方案；¥1000-5000 万 → T2 申请人工复核；≥ ¥5000 万 → T3 引导咨询
4. 输出强制 4 要素（BR-322）

### Requirement 3：业主真假性核验

#### Acceptance Criteria

1. 数据源：工商 + 司法 + 政府公示（[`20-knowledge-system`] 提供）
2. 输出：✅ 通过 / ⚠️ 警告 / 🔴 高风险（含具体证据）
3. 业主信誉评分（融合工商 / 诉讼 / 行政处罚）

### Requirement 4：业主画像

#### Acceptance Criteria

1. 输出：业主基本信息 + 历史项目 + 付款习惯（基于公示信息推测）+ 关联企业
2. 仅 ¥499+ 客户档位可见详细版

### Requirement 5：同行雷达

#### Acceptance Criteria

1. 输出：附近 3 年内 5 个同行最近中标项目 + 中标价 + 业绩积累
2. 推荐报价区间（基于同行中标价 + 该项目特征）

### Requirement 6：自动派单触发

#### Acceptance Criteria

1. 客户对某机会产生**A 类资质需求** → 自动调 [`22-agent-workspace`] dispatch.classify + route
2. 客户对某机会产生**标书代写需求** → 同上

### Requirement 7：边界

1. SHALL NOT 抓取需要登录的招标网（一期）
2. SHALL NOT 提供"项目跟进 CRM"（一期，仅推送 + 收藏）
3. SHALL NOT 替客户决策（仅给评分 + 建议）

### Requirement 8：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`20`]
- 弱依赖：[`14-qualification-guard`]（资质匹配）/ [`22`]（派单）/ [`27`]

## V4 升级：杀手锏 A 精细化（4 块结构）

### Requirement 9：老板视角操作流程（V4）

#### Acceptance Criteria

1. **每天 8:00 自动推送**：5 个匹配机会到首页今日机会卡（含点数）
2. **每条机会卡展示**：
   - 项目名 + 业主 + 金额（脱敏到 ¥X 千万）+ 截止时间
   - AI 评分（0-100 分 + 4 维雷达图：资金 / 资质 / 关系 / 业绩）
   - 业主真假性灯（🟢 通过 / 🟡 警告 / 🔴 高风险）
   - 同行情报（最近 3 年同地区中标价 + 同行排名）
   - 建议报价区间（基于市场参考价库）
   - 5 引导按钮：[一键投标] [申请智能管家] [申请同乾方略] [人工复核] [收藏]
3. **碎片时间**：老板随时打开"招标盲盒"（5 个新机会，开盒看 AI 评分）
4. **关注追踪**：收藏机会 → 招标变更 / 截止前 3 / 1 天提醒
5. **同行雷达深查**（500 点 / 次）：某项目附近 50 公里 / 同行业 3 年内中标项目

### Requirement 10：智能管家视角（V4）

#### Acceptance Criteria

1. **客户机会推送**：智能管家工作台显示归属客户被推送的机会清单（仅高匹配度）
2. **客户预警卡**（22 spec R10）：客户上传招标文件 → 投标需求信号 → 推送智能管家
3. **代客分析**：智能管家可看客户的 AI 报告 7 天窗口期 → 主动联系
4. **派单触发**：客户对某机会产生 A 类标书代写需求 → 自动调 22 dispatch

### Requirement 11：政企视角（V4）

#### Acceptance Criteria

1. 政企版用"项目寻源"替代"机会雷达"（详见 [`23`] R4）
2. 政企不主动追招标（合规要求）
3. 政企可发布"项目寻找施工方"反向匹配建筑企业
