# 16 项目部生产模块 - Requirements

## Introduction

> 功能区 F：项目部日常生产工具（施工日志 / 现场照片 / 签证 / 进度款 / 危大方案 / 资料归档）。仅 ¥499+ 档位可用。

**前置依赖**：[`02`] / [`04`] / [`10`]。

---

## Requirements

### Requirement 1：项目驾驶舱（PM 首页）

#### Acceptance Criteria

1. PM 登录默认首页 = 项目驾驶舱：所属项目卡片 + 待审签证 + 进度提醒 + 关键 KPI

### Requirement 2：施工日志（AI 整理）

#### Acceptance Criteria

1. PM 上传现场照片（≤ 20 张/日）+ 一句话描述
2. AI 自动整理为施工日志 + 标签（部位 / 工序 / 问题）
3. 日志可导出 PDF（按月）

### Requirement 3：联系函（10+ 模板）

1. 变更签证 / 工期延期 / 付款催款 / 设计变更 / 索赔 / 验收 / 安全整改 / 质量整改 / 不可抗力 / 终止合同
2. T1 主动给草稿；按需点击"用印审批"（走 [`06`] 审批引擎）

### Requirement 4：进度款申请

1. 输入完成产值 → AI 出申请文件 + 计算资料表
2. 自动关联合同付款节点（[`13-risk-review`] 提供）

### Requirement 5：危大工程方案

1. 危大工程类型（深基坑 / 高大模板 / 起重吊装 / 脚手架 等）
2. AI 出方案大纲 + 关键风险点 + 安全交底模板
3. T1，但**强制免责声明 + 推送"建议专家论证"**

### Requirement 6：资料归档

1. 资料员（PM_DOC）选项目类型 + 地区 → AI 出归档目录（按地区档案馆要求）
2. 上传现有资料 → 完整性自查 + 缺失清单

### Requirement 7：安全生产辅助提醒（V4 降级版）

> **V4 决策**：原"安全生产 / 实名制 / 工资专户"模块过于专业 + 老板不重视 + 与 AI 工具定位偏离 → 降级为**轻量月度提醒**，不做工作台 / 监管平台对接。

#### Acceptance Criteria

1. SHALL NOT 实现"安全生产工作台"（专家化模块去除）
2. SHALL NOT 实现"实名制管理"（建筑企业不会换平台用）
3. SHALL NOT 实现"农民工工资专户管理"（银行做的事）
4. SHALL NOT 实现"危大工程方案专家论证"（专业造价软件做）
5. **保留轻量月度提醒**（在 R7 项目部消息中心）：
   - 项目所在地的安全生产相关政策更新提醒
   - 项目工期到关键节点（如雨季 / 春节）→ 推送"安全自查清单"模板
   - 资质动态核查中"安全员"岗位变更提醒
6. 这些提醒 SHALL NOT 占据首页 / 主菜单，仅作为"消息中心"推送项

### Requirement 8：边界

1. SHALL NOT 替代专业 BIM / 项目管理软件（仅日常文档辅助）
2. SHALL NOT 替代专家方案论证（强制免责）
3. SHALL NOT 实现安全生产 / 实名制 / 工资专户专业模块（V4 降级）
4. 仅 ¥499+ 档位可见

### Requirement 9：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`07`]（订阅档位检查）
- 弱依赖：[`13`]（合同付款节点）/ [`14`]（资质 / 业绩录入）
