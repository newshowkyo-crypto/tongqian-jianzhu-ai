# 23 政府 / 央国企工作台 - Requirements

## Introduction

> 功能区 L：政策学习 + 公文起草矩阵 + 项目寻源 + 政策性资金作战地图 + 化债投融资咨询 5 大模块。**独立前端 apps/gov**（BR-005 物理隔离）+ 共用后端。
>
> 强制约束（[`requirements.md` R5](../00-project-overview/requirements.md)）：
> - 视觉气质庄重保守（[`ui-visual-spec.md` §9](../../steering/ui-visual-spec.md)）
> - **禁用海外模型**（即使有 BR-505 授权）
> - 字段级权限隔离（财政 / 招商引资敏感字段）
> - 6 年留存 + 独立审计日志
> - 全部公文 / 报告必含"内部使用"水印 + 生成人 + IP 追溯（V4 P4 补丁）

**前置依赖**：[`02`] / [`04`] / [`06`] / [`10`] / [`20-knowledge-system`]。

## Requirements

### Requirement 1：独立前端入口

#### Acceptance Criteria

1. apps/gov 仅 5 模块入口（政策 / 公文 / 寻源 / 资金作战地图 / 咨询入口）
2. SHALL NOT 暴露建筑企业模块（合同审查 / 资质 / 标书等）
3. 视觉按 [`ui-visual-spec.md` §9](../../steering/ui-visual-spec.md)：庄重 + 字号 +1 档 + 移除金色

### Requirement 2：政策学习中心

#### Acceptance Criteria

1. 按级别（中央 / 省 / 市 / 县）+ 主题（基建 / 化债 / 专项债 / 国资）分类（数据来自 [`20`]）
2. 每条新政含"对你单位的影响"AI 解读（含点数 100）
3. 订阅推送（24h 内）+ 红点提示
4. 支持收藏 + 标签 + 全文检索

### Requirement 3：公文 AI 矩阵（V4 升级）

#### Acceptance Criteria

1. **10+ 类党政机关公文模板**：请示 / 报告 / 通报 / 函复 / 督办 / 调研报告 / 讲话稿 / 会议纪要 / 发言提纲 / 工作汇报 PPT 大纲 / 专题方案 / 总结
2. AI 生成符合党政机关公文格式（标题 / 文号 / 主送 / 正文 / 附件 / 落款 / 印发）
3. **严格红线**（[`ai-gateway-rules.md`](../../steering/ai-gateway-rules.md)）：禁政治敏感 + 禁负面表述
4. **强制国产模型**（即使 BR-505 授权也禁海外）
5. 扣点：请示 / 报告 / 通报 200 点 / 调研 300 / 讲话稿 500 / 会议纪要 ASR+整理 300
6. 输出强制水印 + 生成人 + IP（[`28-security-compliance`] R7）
7. **领导讲话稿生成器**：输入 场合 + 主题 + 时长 → 5 分钟 / 15 分钟 / 30 分钟版本
8. **会议纪要 AI 整理**：录音上传 → ASR 转写 → 自动按议题 / 决议 / 任务 / 落款格式整理

### Requirement 4：项目寻源（双向脱敏 + V4 P8 补丁）

#### Acceptance Criteria

1. **政府方主动发布**：项目脱敏摘要（去掉具体单位 / 联系方式 / 金额精确值）→ 推送同地区匹配建筑企业
2. **建筑方主动报送**：建筑企业上报案例 / 资质给政府单位预选
3. SHALL NOT 暴露双方联系方式 直至双方确认意向
4. 双向脱敏聊天通道 + 平台见证记录
5. 双方接受合作 → 平台通知 → 同时脱敏数据进审计日志（6 年留存）
6. **数据出境约束**（V4 P8 补丁）：
   - 项目寻源摘要 SHALL NOT 出境，强制国产模型
   - 双方聊天内容 SHALL NOT 出境，强制国产模型
   - 6 年留存

### Requirement 5：政策性资金作战地图（V4 新增 P2 补丁）

#### Acceptance Criteria

5. 抗灾防灾减灾资金（财政部 + 应急部）
6. 跨区域调水工程资金（水利部 + 发改委）
7. 战略性矿产资源勘查资金（自然资源部）
8. 以工代赈（国家发改委）
9. 脱贫攻坚衔接补助（财政部）
10. 老少边及欠发达地区财政（财政部）

**部委专项 9 项**：

20. 数字中国 / 智慧城市（发改委 + 网信办）

**省级常见专项 8 项**（按省扩展）：

24. 省级新基建专项

**行业基金 / 国资资金 4 项**：

**政策性银行贷款 4 项**：
33. 国开行棚改专项贷
34. 国开行城市更新贷
35. 农发行水利 / 农业贷
36. 政策性开发性金融工具 PSL（央行）

#### R5.2 4 层数据更新机制

1. **Layer 1 自动定时抓取**：每日 6:00 / 12:00 / 18:00 三次扫描财政部 / 发改委 / 住建部 / 各省厅 / 信用中国 / 中国政府网
2. **Layer 2 AI 抽取入待审池**：抽取字段（资金名称 / 主管 / 适用 / 总盘子 / 申报窗口 / 评审要点 / 文件 PDF 链接）
3. **Layer 3 后台运营 1 键扫描**：apps/admin 政策资金管理页 → 红色"立即扫描最新政策"按钮（2 分钟内出结果）
4. **Layer 4 专家审核 → 灰度上线**：周一三五各 1h 由专家审 → 通过 → 灰度 5% → 25% → 100%

#### R5.3 政企前台 3 视图

1. **资金日历**：横向时间轴 + 申报窗口期 + 节点提醒（30/14/7/1 天前）
2. **资金匹配引擎**：输入项目特征 → AI 推荐可申报组合 + 概率 + 申报路径（500 点 / 次）
3. **模板库**：每个资金 → 申报材料清单 + 模板下载 + 历史成功案例脱敏

#### R5.4 资金窗口期智能提醒

1. 用户关注列表（"我感兴趣的资金"）
2. 30 / 14 / 7 / 1 天前自动推送（站内 + 短信 + 公众号 + 邮件）
3. 增量更新机制：内容变更 → 推送 + 标"NEW" + 与原版 diff 高亮

#### R5.5 申报全流程辅助

1. **资金匹配引擎**：500 点 / 次
2. **评审要点解读**：300 点 / 次
3. **一案两书起草**（专项债专用，1500 点 / 次）：
   - 项目实施方案
   - 财评报告（甲级造价咨询机构需加签）
   - 法评报告（律师事务所需加签）
   - 分档限免：¥199 月限 1 次免 / ¥499 月限 3 次免 / ¥999 月限 10 次免（V4 Q3）
4. **项目入库管理**：国家重大 / 国债 / 专项债 一站式录入 + 入库材料检查清单
5. **政策大数据扫描**：实时扫描发改委 / 财政部 / 各省厅 + 命中关键词自动推送
6. **申报成功率排行**：同省同行单位申报成功率 + 失败原因 AI 解读（脱敏）
7. **申报历史追踪**：用户记录申报状态（公示 / 拨付）+ 失败原因 AI 解读 + 改进建议

### Requirement 6：项目台账自动维护

#### Acceptance Criteria

1. 接政府项目库 → AI 抽取 / 整理 / 报表（300 点 / 项目）
2. 月度上报报表自动按"国务院国资委 / 发改委 / 财政部"格式（200 点 / 报表）
3. 投资完成率 / 形象进度 自动汇总 + 异常提醒（100 点 / 月）

### Requirement 7：化债 / 投融资咨询入口

#### Acceptance Criteria

1. ABS / REITs / SPV / 混改 等复杂资本运作 → AI **不直接出方案**（Tier 3 / 4 强制人工接管）
2. 自动转同乾方略人工咨询入口（≥ ¥15 万 / 单）
3. 24h 内顾问联系 + 进度可视化

### Requirement 8：合规要求（V4 P4 / P8 补丁加强）

#### Acceptance Criteria

1. 字段级权限隔离（财政 / 招商引资 / 干部信息 等敏感字段）
2. **数据出境禁用**（即使 BR-505 授权）
3. 独立审计日志（按 PIPL 6 年留存）
4. 数据导出二次审批
5. **公文 / 报告水印**：所有政企版生成的公文 / 讲话稿 / 报告自动加"内部使用，不对外"水印 + 生成人 + 时间 + IP（追溯）
6. 项目寻源数据流强制国产模型 + 6 年留存

### Requirement 9：政企引导按钮（V4 BR-322 升级）

#### Acceptance Criteria

每份报告底部 3 个引导按钮：
1. **自己执行**（直接用方案）
2. **申请同乾方略接管**（大额咨询，Tier 3+ 高亮）
3. **申请专家小时咨询**（同乾团队，¥XXX/小时）

### Requirement 10：政企不参与游戏化

1. 政企版 SHALL NOT 启用上瘾机制：抽点 / 真题 / PK 榜 / 朋友圈 / 段位
2. 仅启用：要情简报（每日）/ 政策快报 / 月度工作小结 / 紧迫感推送（资金申报截止）
3. 合规优先 > 粘性

### Requirement 11：边界

1. SHALL NOT 出具盖章政府方案（仅辅助起草）
2. SHALL NOT 替代政务平台（仅辅助）
3. SHALL NOT 公开存储政府用户身份信息
4. SHALL NOT 让政企用户参与抽奖 / 游戏化（合规）
