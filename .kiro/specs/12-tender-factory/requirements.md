# 12 标书工厂 - Requirements

## Introduction

> **5 大杀手锏 之 2**（功能区 B）：招标解读 + 资格自查 + 标书框架自动生成 + 章节 AI 续写 + 资质资料打包 + 评分预判。
>
> Tier 分级（BR-321）：项目 < ¥1000 万 = T1（全包做完）/ ¥1000-5000 万 = T2（框架 + 关键章节）/ ≥ ¥5000 万 = T3（仅框架 + 引导咨询）。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`20`] / [`21-rules-engine`]（招标规则库）；后续被 [`22`] 派单（标书代写需求）消费。

## Requirements

### Requirement 1：招标文件解读（招标速读）

#### Acceptance Criteria

1. 用户上传招标文件（PDF / Word，≤ 50MB）
2. 5 分钟内输出：核心要点 10 条 + 关键时间表 + 资格要求清单 + 评分标准摘要

### Requirement 2：资格自查

#### Acceptance Criteria

1. 输入：招标资格要求 + 客户企业资质（[`14-qualification-guard`] 提供）
2. 输出：✅ 满足 / ⚠️ 部分 / 🔴 不满足 + 缺失项 + 补救建议
3. 资格不满足时引导：① 找资质智能管家短期借用；② 申请同乾方略协助

### Requirement 3：标书框架生成

#### Acceptance Criteria

1. 5 分钟内输出商务标 + 技术标 双框架
2. 框架包括：章节大纲 + 每章关键要点 + 字数建议
3. 用户可选模板（房建 / 市政 / 公路 等）

### Requirement 4：章节 AI 续写

#### Acceptance Criteria

1. 用户在框架中点击某章节"AI 续写" → 生成草稿
2. 按章节单独扣点（如施工组织设计 = 800 点 / 业绩描述 = 400 点）
3. 用户可"重新生成"（Tier 1 给具体内容；Tier 2 给关键风险点）

### Requirement 5：资质资料打包

#### Acceptance Criteria

1. 一键导出：营业执照 + 资质证书 + 安许 + 业绩 + 主要人员（来自 [`14`]）
2. 生成 PDF 合并包，按招标文件要求顺序排列

### Requirement 6：评分预判

#### Acceptance Criteria

1. 输入：自家投标方案 + 评分标准
2. 输出：预估得分（按评分项细分）+ 关键失分点 + 改进建议

### Requirement 7：自动派单触发

#### Acceptance Criteria

1. 项目 ≥ ¥1000 万 + 客户标 T2/T3 → 自动调 [`22`] 触发"标书代写"派单（A 类，BR-307）
2. 项目 ≥ ¥5000 万 → B 类直接同乾方略接管（BR-307）

### Requirement 8：边界

1. SHALL NOT 替客户填写真实业绩数据（仅整理 + 文字优化）
2. SHALL NOT 自动提交标书（仅生成草稿）
3. SHALL NOT 在 T3 直接给完整标书（防失分）

### Requirement 9：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`14`] / [`20`] / [`21`]
- 后续阻塞：[`22-agent-workspace`] 派单触发

## V4 升级：杀手锏 B 精细化（4 块结构）

### Requirement 10：老板视角操作流程（V4）

#### Acceptance Criteria

1. **接到招标文件 → 一键速读 5 分钟**（800 点）：核心要点 10 条 + 关键时间表 + 资格清单 + 评分摘要
2. **资格自查**（含点数）：✅ / ⚠️ / 🔴 + 缺什么 + 补救建议
3. **5 引导按钮**：
   - [自己写] → 进入框架编辑器
   - [申请标书智能管家代写] → 走 22 dispatch（A 类）
   - [申请同乾方略接管] → ≥ ¥5000 万自动跳同乾货架
   - [申请人工复核] → 投标决策风险高时
   - [申请专家小时咨询] → 临阵问专家
4. **报告底部强制 4 要素 + 难度雷达图**（[`10`] R8）

### Requirement 11：标书员视角（V4）

#### Acceptance Criteria

1. 标书员首页 = 投标工作台：当日机会池 + 在跟项目看板 + 标书草稿列表
2. **标书框架自动生成**（1200 点）：5 分钟出商务标 + 技术标 双框架
3. **章节 AI 续写**（按章节扣点）：
   - 施工组织设计 800 点
   - 业绩描述 400 点
   - 项目管理体系 500 点
   - 质量保障 600 点
   - 安全保障 400 点
   - 应急预案 300 点
4. **标书员每日真题**（钩子 12.6）：每天 1 题 = 1 真实评标案例 + 4 选项 + AI 详解（第 2 题起 50 点）
5. **资料一键打包**：营业执照 + 资质 + 安许 + 业绩 + 主要人员（自动按招标顺序排列）
6. **评分预判**（500 点）：自家方案 + 评分标准 → 预估得分 + 失分点 + 改进
7. **引导按钮**：[继续编辑] [申请智能管家代写] [上报 OWNER]

### Requirement 12：智能管家视角（标书智能管家专属）

#### Acceptance Criteria

1. 接单要求（V4 14 spec R13 协同）：
   - 报价 ≤ 参考价 200%
   - 服务说明 ≥ 200 字
   - 服务周期承诺
   - 失败赔付承诺（30% / 50% / 100%）
2. **智能管家 AI 报价工具**（50 点 / 单）：参考价库 + 历史成交 + 客户特征 → 推荐报价
3. **联合品牌报告**（仅 ¥499+ 客户）：标书框架署名"由 {智能管家公司} 联合 同乾方略 AI 出品"

### Requirement 13：政企视角（业主版）

#### Acceptance Criteria

1. 政企作为业主，可使用"招标文件起草助手"（公文 AI 矩阵的扩展，详见 [`23`] R3）
2. 政企发布招标 → 进入项目寻源池（双向脱敏，详见 [`23`] R4）
