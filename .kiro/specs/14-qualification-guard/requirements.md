# 14 资质智能管家 - Requirements

## Introduction

> **5 大杀手锏 之 3**（功能区 C）：资质体检 + 升级 / 增项路径 + 业绩库 + 安许 + 动态核查。Tier（BR-321）：资质二→一级 = T2；一级 / 特级 = T3。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`20`]（政策 / 业绩库）/ [`21`]（资质规则库）；后续被 [`12`] 资格自查、[`22`] 资质代办派单消费。

---

## Requirements

### Requirement 1：资质档案管理

#### Acceptance Criteria

1. 客户上传现有资质证书（图片 / PDF）→ OCR 抽取关键字段 → 入库
2. 字段：资质类别 / 等级 / 证书编号 / 颁发日期 / 有效期 / 颁发机关
3. 安许证 + 主要人员（建造师 / 安全员 / 八大员）同源管理

### Requirement 2：资质体检

#### Acceptance Criteria

1. 输出健康度评分 + 4 维分项（齐全度 / 有效性 / 升级潜力 / 风险点）
2. 风险点：到期 / 业绩不足 / 主要人员变更 / 安许过期 等
3. 推荐"该补什么 + 该升什么"

### Requirement 3：升级 / 增项路径

#### Acceptance Criteria

1. 输入：当前资质 + 目标资质
2. 输出（按 Tier）：
   - T1（增项 + 二级以下升级）：完整路径 + 业绩 / 人员 / 设备 缺口
   - T2（二→一级）：路径 + 关键风险 + 申请人工复核
   - T3（一级 / 特级）：仅整理 + 引导咨询

### Requirement 4：业绩库

#### Acceptance Criteria

1. 客户录入历史项目业绩（合同 / 中标通知书 / 验收报告）
2. AI 自动整理 + 按资质类别匹配（哪些业绩可用于哪些资质升级）
3. 业绩证书自动打包（[`12`] 资料打包消费）

### Requirement 5：到期监控（BR-604 紧迫感推送 ≤ 3 条/日）

#### Acceptance Criteria

1. 资质 / 安许 / 主要人员证书 距到期 ≤ 90 天 → 推送
2. 推送频率：90 / 60 / 30 / 7 天各 1 次
3. 当日推送上限 3 条（合并 / 优先级）

### Requirement 6：动态核查应对

#### Acceptance Criteria

1. 接收政府动态核查通知 → AI 整理"该准备什么材料 + 关键风险点"
2. T1：完整指南；T2：建议人工

### Requirement 7：自动派单触发

#### Acceptance Criteria

1. 客户产生"资质代办"需求（升级 / 增项）→ 调 [`22`] dispatch
2. 金额阈值（BR-307 / [`packages/constants/dispatch-thresholds.ts`]）：< ¥10 万 → A 类；≥ ¥10 万 → B 类（同乾方略）

### Requirement 8：边界

1. SHALL NOT 自动登录政务平台提交（仅整理材料）
2. SHALL NOT 替换真实业绩（仅整理 + AI 文字优化）

### Requirement 9：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`20`] / [`21`]
- 弱依赖：[`12`] / [`22`] / [`27`]

## V4 升级：智能管家业务延伸 + 挂证合规规避（V4 核心）

### Requirement 10：流量分配逻辑（V4 BR-325 红线 2）

#### Acceptance Criteria

1. **A 类标准资质需求（占 80%）→ 走智能管家**：
   - 续证 / 安许续期
   - 人员补充 / 业绩补录
   - 二级以下升级
   - 增项一般类别
   - 人员社保 / 安许整改
   - 派单逻辑：归属智能管家 24h 优先 → 跨域池（5% 介绍费）→ 公开池

2. **B 类高端 / 复杂需求（占 20%）→ 同乾方略接管**：
   - 一级 / 特级升级
   - 资质合并 / 剥离 / 重组
   - 央国企资质规划
   - 涉诉资质问题
   - 直接进同乾方略服务货架
   - 归属智能管家拿 10-15% 推荐费

3. **AI 输出明确引导**：
   - 资质升级路径报告底部强制"申请智能管家协助"按钮（不强制选）
   - 续证 / 升级类报告底部含"建议本月内联系智能管家张管家"（带归属智能管家信息）

### Requirement 11：智能管家专属工具（V4 新增）

#### Acceptance Criteria

#### 工具 1：客户资质档案库
- 智能管家工作台权限：看自己归属客户的所有档案
- 一键导出客户资质画像 PDF（个性化报价用）
- 客户资质到期 90/60/30 天 → 站内 + 短信提醒
- 续证窗口期自动报价模板

#### 工具 2：AI 升级路径规划器（智能管家给客户出方案的工具）
- 输入：客户当前资质 + 想升级目标
- AI 输出：资质标准对照（住建部最新）+ 缺什么人员 / 业绩 / 设备 / 注资 + 补齐成本估算 + 周期估算
- 工具自动生成 PDF（智能管家公司 LOGO + 同乾方略联合品牌）

#### 工具 3：人员匹配池（替代挂证，合规化）
- **违规模式（禁止）**：
  - × 挂证：人证分离，证书租赁
  - × 假社保：代缴社保规避连续性
- **合规模式（鼓励）**：
  - ✓ 真用工：建造师人才池，全职 / 兼职明确分类
  - ✓ 项目劳务派遣：通过劳务公司合规派遣
  - ✓ 联合体投标：缺资质时通过联合体补齐
- 平台具体做法：
  1. SHALL NOT 提供"挂证渠道"
  2. 提供"建造师真用工求职池"（带社保连续性核验）
  3. 提供"联合体撮合"
  4. 提供"全国建筑市场监管平台"实时核验（人证一致 + 社保唯一性）
  5. AI 检测异常 → 风险预警，但不强制举报

#### 工具 4：业绩库自动匹配
- 业绩库：客户所有项目（业主 + 类型 + 金额）
- AI 自动匹配：哪些业绩可作为下次升级支撑 / 投标响应 / 需要业主出具证明

#### 工具 5：智能管家收益结算（资质类专项）
- 资质代办服务费（智能管家与客户私下结算）：平台 0 抽成
- + 平台抽订阅分润（30/20/15%，BR-302）
- + 同乾方略 B 类推荐费（10-15%）
- + 续证 / 升级提醒触发的客户复购 → 全部分润给智能管家

### Requirement 12：挂证合规规避机制（V4 核心）

#### Acceptance Criteria

#### R12.1 被动规避

1. 平台 SHALL NOT 开"挂证撮合"功能（产品边界硬约束）
2. 智能管家工作台 SHALL NOT 展示"代办挂证"服务类型
3. 报价单模板含"承诺合规用工"勾选项（智能管家必勾）
4. 智能管家注册 5 项合规承诺（[`28`] R5）含"承诺合规用工，不参与挂证"

#### R12.2 主动核验

1. AI 自动核验四库一平台：
   - 人员社保唯一性（同人 ≠ 多企业社保）
   - 项目业绩唯一性（同项目 ≠ 多企业重复申报）
   - 证书项目业主三方一致性
2. 异常检测 → 弹窗预警 + 写审计日志：
   ```
   "检测到该建造师本月在另一企业有社保记录，
    建议核实是否符合用工合规要求。"
   ```
3. 智能管家可见预警 + 跨域共享黑名单（合规协同）

#### R12.3 处罚

1. 智能管家发起挂证服务被发现 → 扣信誉 -300 + 黑名单（终身封禁）
2. 客户参与挂证被发现 → 客户信誉一票否决 + 限制后续派单
3. 写审计日志 6 年留存（PIPL）

### Requirement 13：派单标准（V4 资质类专属覆盖 BR-336）

#### Acceptance Criteria

```
分数 = 归属优先(100) + 地区(20) + 子类匹配(30)
     + 信誉等级(LV1+1 ~ LV5+20)
     + 月度满意度(5★+10 / 4★+5 / 3★+0 / <3 不进池)
     + 历史成功率(同类资质成功 +5 / 件)
     + 响应速度(平均接单时长 < 2h +5)
     + 价格区间合理度(参考价 ±10% +5)
```

最高分先派单 → 1h 抢单窗口 → 不接降级

接单要求（强约束）：
1. 报价 ≤ 参考价 200%（超过自动转客服核验）
2. 服务说明 ≥ 200 字
3. 服务周期承诺（精确到自然日）
4. 失败赔付承诺（30% / 50% / 100% 三档可选）
5. 接单后 48h 内必须线下首次沟通

结算保护：
- 客户付款 → "冻结" 7 天保护期
- 智能管家完成里程碑 1（人员补足）→ 解冻 30%
- 完成里程碑 2（业绩补录）→ 解冻 30%
- 最终交付 + 客户验收 → 解冻 40%
- 全部解冻 → 30 天客户验收期
