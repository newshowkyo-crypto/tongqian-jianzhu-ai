# 19 现金流 / 融资轻量版 - Requirements

## Introduction

> 功能区 I：应收账款 + 现金流 + 建筑企业自身融资轻量诊断。Tier（BR-321）：
> - 应收 < ¥500 万 = T1；¥500-2000 万 = T2；≥ ¥2000 万 = T3
> - 融资授信 < ¥5000 万 = T2；≥ ¥5000 万 = T3（化债 / ABS / REITs 自动 B 类同乾方略）

**前置依赖**：[`02`] / [`04`] / [`10`]；后续触发 [`22`] B 类派单（融资 / 化债）。

---

## Requirements

### Requirement 1：应收账款看板

#### Acceptance Criteria

1. 上传应收账款 Excel → AI 账龄分析（30/60/90/180+ 桶）
2. 风险评分：客户信用 / 历史付款 / 关联方
3. 现金流压力测试：未来 3-12 月预测

### Requirement 2：催收函（与 [`15-ops-toolkit`] 联动）

1. 一键群发不同语气催收函（30-60 温和 / 60-90 明确 / 90+ 法律风险）
2. 升级到同乾方略人工催收（T2/T3）

### Requirement 3：融资可能性诊断

1. 输入：企业资质 / 业绩 / 应收 / 财报关键指标
2. 输出（T1/T2）：可融资类型 + 大致额度 + 关键准备
3. T3（≥ ¥5000 万）/ ABS / REITs / 化债 → 引导同乾方略咨询（[`22`] premium-shelf）

### Requirement 4：金融服务智能管家撮合

1. 应收 ≥ ¥500 万 → 推荐保理 / 保函 / 设备融资 类金融智能管家（[`22`] A 类派单）
2. ≥ ¥5000 万 → 直接 B 类同乾方略

### Requirement 5：现金流预警

1. 关键指标越界 → 推送（如经营现金流连续 3 月负值）

### Requirement 6：边界

1. SHALL NOT 出具盖章财务报告
2. SHALL NOT 替代企业 ERP（仅轻量管理）
3. SHALL NOT 在 T3 直接给融资方案

### Requirement 7：依赖

- 强依赖：[`02`] / [`04`] / [`10`]
- 弱依赖：[`14`]（资质对融资影响）/ [`22`]（金融智能管家派单 + 同乾方略）/ [`15`]（催收函）
