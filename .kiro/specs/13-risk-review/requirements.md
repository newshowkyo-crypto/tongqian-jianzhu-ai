# 13 风险审查 - Requirements

## Introduction

> **5 大杀手锏 之 4**（功能区 D）：合同 / 招标 风险审查 + 修改意见函 + 索赔策略。Tier 分级（BR-321）：项目 < ¥1000 万 = T1 / ¥1000-5000 万 = T2 / ≥ ¥5000 万 = T3。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`21-rules-engine`]（合同风险规则库）。

---

## Requirements

### Requirement 1：合同审查（基础版 + 专业版）

#### Acceptance Criteria

1. **基础版**（300 点 / 单）：上传合同 PDF / Word → 30 秒内返回老板版 H5（≤ 3 屏）
2. **专业版**（1500 点 / 单）：5 分钟内返回详细版 PDF（含修改意见函）
3. 输出含：总体风险等级（红 / 黄 / 绿）+ 5 关键发现 + 详细风险条款列表 + 修改建议 + 标准条款参考

### Requirement 2：招标文件风险审查

#### Acceptance Criteria

1. 重点审查：陷阱条款（无限连带 / 工期违约金过高 / 付款节点推迟 / 业主单方解除权 等）
2. 输出风格同合同审查

### Requirement 3：修改意见函生成

#### Acceptance Criteria

1. T1：直接生成对方可接受的修改函（含标准措辞）
2. T2：给出关键风险点 + 建议申请人工复核
3. T3：仅整理风险点 + 引导咨询

### Requirement 4：索赔策略（高级）

#### Acceptance Criteria

1. T2 起：根据合同条款 + 现实情况，给出索赔依据 + 证据清单 + 步骤建议
2. T3：仅整理依据，不给具体策略
3. T4：涉诉案件强制人工接管（[`design.md` BR-321](../00-project-overview/design.md)）

### Requirement 5：6 大常见风险类型

1. 无限连带 / 不限额担保
2. 工期违约金过高
3. 付款节点不合理
4. 业主单方解除权 / 终止权
5. 不合理变更 / 索赔限制
6. 知识产权 / 保密过分约束

### Requirement 6：边界

1. SHALL NOT 出具正式法律意见（强制免责声明）
2. SHALL NOT 直接代签 / 改合同（仅给意见）
3. T4（涉诉）SHALL 自动转人工咨询

### Requirement 7：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`21`]
- 弱依赖：[`22`] 标书代写 + 合同纠纷派单

## V4 升级：杀手锏 C 精细化（4 块结构）

### Requirement 8：老板视角操作流程（V4）

#### Acceptance Criteria

1. **30 秒老板版风险审查**（300 点）：
   - 上传合同 PDF / Word
   - 30 秒内输出 H5 风险卡（≤ 3 屏，3 分钟读完）
   - 总体红 / 黄 / 绿 灯
   - 5 个关键发现（每条含红黄绿色码）
   - 老板版 = 简单语言，避免法律术语
2. **5 分钟详细版 PDF**（1500 点）：
   - 详细风险条款列表
   - 修改建议 + 标准条款参考
   - 修改意见函（可直接发对方）
3. **6 大风险类型识别**：
   - 无限连带 / 不限额担保
   - 工期违约金过高
   - 付款节点不合理
   - 业主单方解除权 / 终止权
   - 不合理变更 / 索赔限制
   - 知识产权 / 保密过分约束
4. **5 引导按钮**：
   - [按修改意见函发对方]（自己执行）
   - [申请智能管家协助沟通]（智能管家代发 + 跟进）
   - [申请同乾方略接管]（≥ ¥5000 万 / 涉诉自动高亮）
   - [申请律师人工复核]
   - [申请专家小时咨询]
5. **难度雷达图**（[`10`] R8）：自己沟通修改 vs 申请智能管家代沟通 对比

### Requirement 9：法务岗视角（V4）

#### Acceptance Criteria

1. 法务首页 = 法务工作台：合同审查队列 + 月度风险体检 + 法律咨询对话历史
2. **批量审查模式**：上传 5+ 合同 → 批量出报告（按风险等级排序）
3. **法律咨询对话**（100 点 / 轮）：日常法律问题 AI 解答（小风险）
4. **月度风险等级体检**（500 点 / 月）：按租户全部合同自动 → 红黄绿三色清单
5. **修改意见函库**：保存历史修改函 + 复用模板
6. **引导按钮**：[审完发 OWNER] [申请律师人工复核] [上报 OWNER]

### Requirement 10：智能管家视角（V4）

#### Acceptance Criteria

1. 智能管家工作台 SHALL NOT 直接出合同审查报告（这是法务专业领域）
2. 智能管家可看归属客户的合同审查报告 7 天窗口期 → 主动联系
3. 客户合同涉合规问题 → 智能管家可推送同乾方略接管
4. 智能管家不得替客户决策合同条款（法律责任）

### Requirement 11：政企视角（V4）

#### Acceptance Criteria

1. 政企采购合同 / 委托合同 / 服务合同审查同建筑老板版
2. **强制国产模型**（即使 BR-505 授权，避免数据出境）
3. **强制水印 + traceId**（[`28`] R7）
4. ≥ ¥1000 万 / 涉诉 → T3/T4 强制人工接管
