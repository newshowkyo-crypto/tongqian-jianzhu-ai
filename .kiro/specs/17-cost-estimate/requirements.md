# 17 造价 / 预算粗判 - Requirements

## Introduction

> 功能区 G：粗估 / 清单 / 报价 / 材料价 4 项。**粗判精度 ±20%-30%**（[`requirements.md` R10.5](../00-project-overview/requirements.md)），SHALL NOT 替代专业造价软件（广联达 / 品茗）。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`20-knowledge-system`]（材料价 + 历史造价库）/ [`21`]（造价规则库）。

---

## Requirements

### Requirement 1：项目造价粗估

#### Acceptance Criteria

1. 输入：项目类型 + 建筑面积 + 地区 + 结构类型 + 装修标准
2. 输出：单方造价 + 总造价（带 ±20%-30% 区间）+ 可比项目对照
3. T1（始终给参考），但**强制免责**

### Requirement 2：清单合理性检查

1. 上传清单 Excel → AI 检测：项目缺漏 / 单价偏离参考价 / 工程量异常
2. 输出标记 + 修改建议

### Requirement 3：报价辅助

1. 输入项目特征 → 推荐"投标 / 谈判 / 让利" 三档报价
2. 与同行雷达（[`11`]）+ 参考价库（[`21`]）联动

### Requirement 4：材料价查询

1. 当前主要建材价（钢筋 / 水泥 / 混凝土 / 木材 等）按地区
2. 趋势图（最近 30 天）
3. 价格预警（涨跌幅 ≥ 5%）

### Requirement 5：边界

1. SHALL NOT 替代专业造价软件
2. SHALL NOT 出具盖章造价报告
3. SHALL NOT 实现 BIM 算量（仅按经验粗估）

### Requirement 6：依赖

- 强依赖：[`02`] / [`04`] / [`10`] / [`20`] / [`21`]
- 弱依赖：[`11`]（同行雷达）/ [`12`]（标书报价）
