# 15 经营成本工具集 - Requirements

## Introduction

> **5 大杀手锏 之 5**（功能区 E）：AI 老板助理 + 6 大日常钩子 + 财务 / 商务 / 资料员工具 + 政企公文矩阵。这是平台扣点收益最大的功能区（占总扣点 40-50%）。
>
> **V4 升级**：从"杂物筐"重定义为"老板每天必开的 AI 副手中枢"。
>
> Tier：大部分 T1（日常）；少量 T2（金融纠纷）；T3 / T4 强制接管。

**前置依赖**：[`02`] / [`04`] / [`10`] / [`20-knowledge-system`]（政策库）/ [`14`] / [`16`] / [`19`]（数据来源）。

## Requirements

### Requirement 1：AI 老板助理对话（核心入口，BR-325 V4）

#### Acceptance Criteria

#### R1.1 入口分发（V4 Q5）
1. 所有老板对话入口走 E（AI 老板助理）→ 内部分发到 ABCDE 5 大模块
2. 对话流程：用户提问 → 意图识别（10 点）→ 路由到主任务（资质 / 招标 / 合同 / 标书 / 政策 / 内部数据）→ 主任务扣点
3. SHALL NOT 让老板自己选去 D 还是 E（老板只感觉"我和 AI 助理聊了一会儿"）

#### R1.2 6 大日常对话场景

1. **决策咨询**："中铁建给的合同条款值不值得签"→ 调 13-risk-review + 历史合同对比
2. **内部数据问答**："上个月哪个项目利润最高？谁负责的？"→ 调本租户业财数据 + 直接出表格（100 点）
3. **行业询问**："湖北明年专项债重点投哪些方向？"→ 调 20 政策库 + 给出本企业建议
4. **文档代笔**："给中铁建写封投标致谢函"→ 调 15 模板库
5. **同行对标**："我们公司在湖北二级总包里排第几？"→ 调四库一平台 + 同行 PK
6. **情绪 / 闲聊**："今天烦死了"→ 简短共情 + 推一条"今日好消息"

#### R1.3 5 个聊天上瘾钩子（V4 新增）

1. **AI 助理"养成系"**：
   - 连续 7 天对话 → 解锁"了解你的公司"标签
   - 连续 30 天 → 解锁"懂你脾气"标签 + AI 学会用你口吻签批
   - 连续 100 天 → 解锁"老搭档"标签 + 实物礼品（同乾方略定制黑色笔记本）
   - 连续 365 天 → 解锁"年终回顾报告 我和 AI 的 365 天"

2. **灵感卡**（V4 Q4）：
   - 4 条件触发：今天对话 ≥ 3 句 + 真实情报 + 主题相关 + 24h 未推送过
   - 默认每天 1 张主动推送（可关闭）
   - UI：不打断对话，对话结束后弹底部小卡

3. **历史话题主动提**（防失忆 / 强陪伴感）：
   - 早上打开 → AI 主动说："上次咱们聊到武汉地铁项目的可投性还没定，昨晚招标更新了 3 条要点，要不要再聊聊？"

4. **AI 性格选择**（个性化）：
   - 4 种风格：严谨型（数据为王）/ 江湖型（兄弟口吻）/ 学术型（引用条款 + 案例）/ 女管家型（温柔 + 提醒）
   - 默认严谨型，江湖型用户主动选才启用
   - 每周可切换 1 次（频繁切换会失去人设积累）

5. **对话连胜任务**（每天 3 次）：
   - □ 跟 AI 聊 ≥ 3 句  +5 点
   - □ 让 AI 帮查 1 条数据  +5 点
   - □ 让 AI 帮写 1 份文档  +10 点
   - 连续 7 天全勤 → 周末抽 1 次 1000 点（V4 Q3：不发现金，避税）
   - 连续 30 天 → 月底解锁稀有勋章

### Requirement 2：6 个高频钩子（V4 核心）

#### R2.1 早安 AI 简报（50 点 / 天，V4 Q1）

##### Acceptance Criteria

1. 每天 7:30 自动推送（站内 + 公众号）
2. 90 秒读完 5 条干货：政策 / 机会 / 风险 / 同行 / 数据
3. 个性化（含老板姓 + 公司名 + 本省数据）
4. 月度按档限免：trial 5 天 / ¥39 档 20 天 / ¥199 档工作日不限 / ¥499+ 不限
5. 输出红线（详见 [`26`] R13）：每条 ≥ 30 字 + 含数字 + 时间 + 来源 + SHALL NOT 套话广告

#### R2.2 决策小测（每天 1 题免，第 2 题 50 点，V4 Q2）

##### Acceptance Criteria

1. 1 题 = 1 真实案例（来自规则库 / 案例库 / 历史合同纠纷）
2. 4 选项必须有迷惑性（SHALL NOT ABC 明显错）
3. AI 详解必须含：法律 + 行业惯例 + 失败案例 + 建议
4. 每天 1 题免费 + 第 2 题起扣 50 点
5. ¥499+ 不限免费（养成知识打卡习惯）

#### R2.3 同行情报快闪（100 点 / 次查询）

##### Acceptance Criteria

1. 实时推送：检测到本省同行新中标 → 推送
2. 一键深查：查招标方真假性 / 业主资信 / 同行背景
3. 上限 ≤ 3 条 / 天（防 spam）
4. 输出红线：基于真实数据（中标公告 / 招投标 / 四库一平台）+ SHALL NOT 推送陈旧 / 不准 / 误导信息

#### R2.4 AI 周报（200 点 / 周）

##### Acceptance Criteria

1. 每周一 8:00 自动生成（订阅 ¥199+）
2. 含本租户真实数据 + ≥ 5 个 KPI + 3 个待办 + 2 个建议 + 环比对比
3. 输出红线：SHALL NOT 全是套话，必须基于真实数据

#### R2.5 公文 / 商务函代写（30-200 点）

##### Acceptance Criteria

1. 10+ 类商务模板：邀请函 / 致谢函 / 月报 / 接待方案 / 述职 / 年终总结 / 报价单 / 答复函 / 客户关系备忘 / 招投标准备清单
2. 每函扣点 30-100 点
3. 输出红线：符合党政机关 / 商务格式规范 + 可直接打印盖章 + 完整要素

#### R2.6 灵感卡（30 点 / 次，自动推送 0 点，V4 Q4）

##### Acceptance Criteria

1. 4 条件触发（详见 R1.3.2）
2. 每张卡 = 1 条情报 + 1 个动作建议
3. 输出红线：基于本周本地真实情报 + SHALL NOT 推广 / 鸡汤

### Requirement 3：财务岗专属工具

#### Acceptance Criteria

1. **应收账款看板**（200 点 / 次）：上传 Excel → AI 账龄分析 + 风险评分 + 现金流压力测试
2. **一键催款函**（30 点 / 函）：按账龄分级（30-60 温和 / 60-90 明确 / 90+ 含法律风险）+ 自动调历史合同条款
3. **现金流预测**（300 点 / 次）：接业财数据 → 未来 3/6/12 个月预测
4. **发票管理**：自动开票 + 月度汇总（功能 0 点）
5. **融资可能性诊断**（500 点）：应收 ≥ ¥500w → 推送 → 进 [`19`]

### Requirement 4：商务岗专属工具

#### Acceptance Criteria

1. **邀请函 / 报价单 / 答复函 / 致谢函** 30-100 点 / 类
2. **客户关系备忘**（50 点 / 次）：上次见面记录 + 下次跟进建议 + 客户偏好分析
3. **招投标准备清单**（100 点 / 项目）：输入项目编号 → AI 生成本企业准备物料清单

### Requirement 5：资料员岗（仅 ¥499+ 解锁）

#### Acceptance Criteria

1. **归档目录生成**（100 点 / 项目）：按地区档案馆要求
2. **完整性自查 + 缺什么**（50 点 / 项目）
3. **八大员表格批量**（200 点 / 批）

### Requirement 6：法务岗

#### Acceptance Criteria

1. **法律咨询对话**（100 点 / 轮）：小风险问题 + AI 引用法规 + 案例 + 建议
2. **风险等级体检**（500 点 / 月）：按租户全部合同月度自动 → 红黄绿三色清单
3. 注：合同审查走 [`13-risk-review`] 杀手锏 C，本模块只补"日常对话 / 月度体检"

### Requirement 7：政企岗（V4 P2 协同）

详见 [`23-gov-soe-workspace`] R3 / R5 / R6。本模块仅提供以下技术支撑：

1. **公文 AI 矩阵**（10+ 类）：请示 / 报告 / 通报 / 调研 / 讲话稿 / 会议纪要 / 发言提纲 / PPT 大纲 / 专题方案 / 总结
2. **领导讲话稿生成器**：场合 + 主题 + 时长 → 5 / 15 / 30 分钟版本
3. **会议纪要 AI 整理**：录音上传 → ASR + 自动整理纪要
4. **项目台账 AI 维护**：投资完成率 + 形象进度 + 异常提醒
5. **政策性资金作战地图**：30+ 资金 + 4 层更新 + 一案两书起草

### Requirement 10：边界

1. SHALL NOT 替代专业法律 / 财务咨询（Tier 边界）
2. SHALL NOT 直接发送邮件 / 短信（仅生成内容）
3. SHALL NOT 在 T2 任务中越界（如金额纠纷 ≥ ¥500 万 → T2 强制建议人工）
4. SHALL NOT 故意输出残缺方案（V4 BR-325 红线 1）
5. SHALL NOT 让 AI 替代智能管家职责（V4 BR-325 红线 2）
