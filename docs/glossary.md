## 0. 命名映射（核心 — 写代码必看）

> **2026-05-16 ADR-AUTO 双轨命名规则**：用户可见层（UI / 报告 / 营销 / 协议 / spec 自然语言）统一用"智能管家"。代码层（数据库表 / 字段 / API / enum / 目录）保持英文 `agent` 标识符不变。详见 [`2026-05-16-adr-auto-rename-agent-to-steward.md`](./decisions/2026-05-16-adr-auto-rename-agent-to-steward.md)。

| 用户可见 | 代码标识符（不变）| 规则 |
|---|---|---|
| 智能管家 | `agent` / `Agent` / `AGENT` | 中文文案统一从 i18n 取 `t('agent.title') = '智能管家'` |
| 智能管家工作台 | `apps/agent/` | 目录名英文不变 |
| 资质智能管家 | `AgentSubtype.AGENT_QUAL` | enum 值英文不变 |
| 标书智能管家 | `AgentSubtype.AGENT_TENDER` | |
| 金融智能管家 | `AgentSubtype.AGENT_FIN` | |
| 综合智能管家 | `AgentSubtype.AGENT_GENERAL` | |
| LV1 见习管家 / LV2 入职管家 / LV3 资深管家 / LV4 金牌管家 / LV5 首席管家 | `AgentLevel.LV1`～`LV5` | 数字代号不变，对外名称走 i18n |

## 13.5 派单与服务质量术语（详见 ADR-002）

| 术语 | 定义 |
|---|---|
| 派单需求 A 类 | 标准智能管家服务（资质 < ¥10 万、标书 < ¥3 万、融资 < ¥5000 万 等），派给智能管家 |
| 派单需求 B 类 | 高端 / 复杂服务（化债 / ABS / REITs / 一级资质 等），同乾方略直接接管 |
| 派单需求 C 类 | 灰色地带（标准服务但金额超阈值），自动升级为 B 类 |
| 派单池 | 智能管家池统称，分归属池 / 跨域池 / 公开池 三层递进 |
| 归属池 | 客户绑定的智能管家专属池，优先派单 |

| 4 维加权匹配 | 地区 + 业务子类 + 智能管家等级 + 月度评分 加权评分 |
| 抢单窗 | 智能管家接单时间窗（归属 24h、抢单池 1h）|

| 报价标色 | 智能管家报价对比参考价的颜色标记（绿/黄/红/超价）|
| 同乾方略接管 | 触发 6 条件后订单自动 / 主动转入同乾方略服务 |

| 同乾方略推荐费 | 智能管家推荐的客户被同乾方略接走时给智能管家的分成（10–20%）|
| 跨域介绍费代扣代付 | 跨域派单时平台代扣 5% 给归属智能管家，不计平台收入 |

## 13.6 信誉机制术语（详见 ADR-002 §2.7）

| 术语 | 定义 |
|---|---|
| 智能管家信誉分 | 0–1000 分，基础 500，根据行为加减，决定派单优先级 / 推荐费上限 / 提现周期 |
| 客户信誉分 | 0–1000 分，基础 500，**挂在 tenant（企业）维度**，企业内所有用户行为聚合，影响后续派单 |
| 智能管家等级 LV1–LV5 | 基于信誉分自动评定：LV1 见习管家 / LV2 入职管家 / LV3 资深管家 / LV4 金牌管家 / LV5 首席管家 |
| 新智能管家保护期 | 新智能管家注册后 30 天内最低不降到 LV1（最低保 LV2 入职管家），让其有上手机会 |
| 信誉加分 | 完成订单 / 好评 / 推荐 / 培训 / 月活 等正向行为 |
| 信誉减分 | 差评 / 投诉 / 超价 / 不接单 / 暂停 / 违规 等负向行为 |
| 信誉自然回血 | 每月活跃 + 无差评 → +20/月（缓慢恢复机制）|
| LV1 重启计划 | LV1 智能管家每月平台兜底派 1 单试水订单，完成 ≥4★ 加 +50/单，加速恢复，终身最多 6 次 |
| 信誉申诉 | 智能管家对扣分项在 7 天内发起申诉，走三级流程 |
| 信誉公开度 | 智能管家分对客户公开；客户分仅接单智能管家可见；智能管家自己看不到公式细节 |
| 优质客户标识 | 客户信誉 ≥ 800 时自动获得，吸引高质量智能管家接单 |
| 首席管家标识 | LV5 首席管家自动获得，公开展示给客户 |
| 提现周期 T+N | 智能管家提现到账天数，等级越高越快（LV5 = T+0 即时到账）|

## 13.7 AI 边界术语（详见 ADR-002 §2.8）

| 术语 | 定义 |
|---|---|
| AI 输出 Tier 1 | 小单 / 日常，AI 主动给方案，无需人工复核 |
| AI 输出 Tier 2 | 中单，AI 给框架 + 提示，强制 "申请人工复核" 按钮 |
| AI 输出 Tier 3 | 大单，AI 仅做信息整理，不出方案，必须引导申请同乾方略 |
| AI 输出 Tier 4 | 极复杂，AI 拒绝直接给意见，自动跳转人工咨询 |
| AI 信心度 | AI 对当前任务的把握度（高/中/低），基于规则匹配度 + 案例覆盖度 |
| AI 报告强制要素 | 免责声明 + Tier 等级 + 信心度 + 建议下一步 |
| 让企业先尝试自做 | Tier 2/3 任务先引导用户自己消化，再推荐人工，避免上来就推销 |
