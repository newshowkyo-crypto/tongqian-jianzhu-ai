- Sales demo mode added at `/demo/[slug]` for five killer scenarios.

## Micro-Interactions

- Button: hover scale, elevated shadow, active press, disabled cursor/opacity, loading spinner support.
- Card: hover translateY and deeper shadow, active inset feel.
- DataTable: row hover gradient, selected row rose-gold left indicator support.
- Input/Textarea: focus glow and error shake class.
- Number/KPI: existing `AnimatedNumber` CountUp kept at 800ms.
- Loading/Empty/Error: shimmer skeleton class and polished H5 visual shell added.
