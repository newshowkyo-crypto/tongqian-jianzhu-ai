# M3.12 Domestic Flagship AI Routing

Date: 2026-05-21

## Routing Lock

M3.12 switches AI routing to China-only flagship providers:

| Route class | Provider | Model | Usage |
| --- | --- | --- | --- |
| Reasoning | DeepSeek direct | `deepseek-reasoner` | contract review pro, tender framework, qualification upgrade, policy impact, financing diagnosis, high-risk analysis |
| Daily text | Aliyun DashScope | `qwen3-max` | AI assistant, morning briefing, KPI Q&A, official documents, letters, work reports |
| Vision | Aliyun DashScope | `qwen3-vl-max` | drawing understanding, scanned contracts, tender OCR, certificate recognition |
| Embedding | Aliyun DashScope / DashVector | `text-embedding-v3` | RAG recall and semantic cache |

OpenRouter, Claude, GPT and B.AI are no longer callable routes. The OpenRouter provider code remains only as a deprecated enum/audit compatibility shell marked `DEPRECATED_DO_NOT_USE`.

## Code Changes

- `default-routing.ts` now builds every `AiTaskType` route from domestic providers only.
- `provider-router.service.ts` exposes callable providers for DeepSeek reasoner and DashScope qwen3-max/qwen3-vl-max/text-embedding-v3 only.
- `gov-domestic-only.guard.ts` forces government/SOE AI requests to DashScope `qwen3-max`.
- Prompt metadata defaults moved from `deepseek-chat` to `qwen3-max`, while deep-analysis prompts keep `deepseek-reasoner`.
- Health and metrics now report DeepSeek reasoner, DashScope text/vision/embedding, DashVector deferred status, and OpenRouter deprecation.
- `.env.example` and `.env.dev.template` now document the final domestic AI configuration.
- Real AI tests now run DeepSeek reasoner and DashScope qwen3-max when keys are present; OpenRouter is permanently skipped.
