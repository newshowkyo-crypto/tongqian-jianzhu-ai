# 商业模型（Business Model）

> 描述同乾方略 · 建筑 AI 经营管家的商业逻辑、定价、分润、运营、推广策略。
> 工程师在写代码时遇到商业逻辑问题，先来这里查。

## 1. 一句话定位

**同乾方略 · 建筑 AI 经营管家** = 中小建筑企业日常 AI 工具平台 + 同乾方略高端咨询获客器。

## 2. 商业闭环（核心）

```
第 1 层｜AI 工具订阅（月付 39 / 199 / 499 / 999 + 试用免费）
        ↓ 客户在平台沉淀经营数据 + 暴露需求
第 2 层｜智能管家标准服务派单（资质 / 标书 / 保函）
        ↓ 智能管家赚自己擅长的钱，平台几乎不抽
第 3 层｜同乾方略标准咨询（5–20 万 / 单）
        ↓ AI 报告标记"超智能管家能力"自动转你团队
第 4 层｜同乾方略战略顾问（50–500 万 / 单）
        年度签约、政府 / 央国企客户
```

**核心理念**：SaaS 是"鱼塘"，智能管家是"渔民"，同乾方略是"卖鱼老板"。

## 3. 用户大类（4 类）

注册时只有 4 大角色：
- **建筑企业用户** (BUILDING_COMPANY)：内部按岗位标签分配权限（老板/经营/标书/项目经理/资料员/安全员/财务/HR/法务等 30+ 岗位）
- **政府 / 央国企用户** (GOV_USER / SOE_USER 合并)
- **智能管家用户** (AGENT)：内部分类型（资质/投标/金融/综合）
- **平台运营用户** (PLATFORM)：超管/运营/财务/客服/专家/顾问/审计

## 6. 智能管家裂变（三层）

### 第 1 层：智能管家 → 客户

```
推广方式：链接 / 二维码 / 朋友圈卡片 / 体检钩子
分润：
  - 客户首年订阅：30%
  - 客户次年起订阅：20%
  - 客户充值流水：15%
  - 派单服务费：客户付给智能管家，平台不抽
  - 跨域派单：派单方 5%，服务方 95%
归属：永久（不会被抢）
```

### 第 2 层：智能管家 → 智能管家

```
老智能管家推荐新智能管家加盟：
  - 永久 10% 分润（新智能管家所有分润的 10%）
  - 新智能管家首笔分润达 ¥1000 时一次性奖 ¥200 给老智能管家
  - 二级封顶（不能再下级）
```

### 第 3 层：客户 → 客户

```
客户邀请同行：
  - 邀请方得 200 点
  - 被邀请方首单成功，邀请方再得 10% 现金红包
  - 每人每月限 5 个邀请
```

## 6.5 派单决策树（核心商业逻辑，详见 ADR-002）

平台对客户出现的服务需求按 **A / B / C 三类**分流：

### A 类 标准智能管家服务（派给智能管家）

| 服务 | 阈值 | 谁接 |
|---|---|---|
| 资质代办 | < ¥10 万 服务费 | 智能管家 |
| 标书代写 | < ¥3 万 服务费 / 项目 < ¥5000 万 | 智能管家 |
| 保函撮合 | 全部 | 智能管家 |
| 建企流贷 | < ¥5000 万 授信 | 智能管家 |
| 农民工保函 / 设备融资 | 全部 | 智能管家 |
| 应收保理 | < ¥2000 万 | 智能管家 |

### B 类 高端服务（同乾方略直接接管）

明码标价的高端服务货架，**不走智能管家池**：

| 服务 | 价格 | 智能管家推荐费 |
|---|---|---|
| 年度战略顾问 | ¥30–50 万/年 | 10–15% |
| 化债策略 | ¥50 万起 | 10–15% |
| ABS / ABN / REITs | ¥100 万起 | 10–15% |
| 混改 / 并购 / SPV | ¥80 万起 | 10–15% |
| 央国企融资规划 | ¥30–100 万 | 10–15% |
| 重大项目陪标 | ¥10–30 万 | **15–20%** |
| 资质一级 / 特级升级 | ¥15–30 万 | 15% |
| 政府专项债策划 | ¥30 万起 | 10–15% |
| PPP / TOT / EOD | 协议定价 | 10–15% |
| 跨境投融资 | 协议定价 | 10–15% |

### C 类 灰色地带（自动升级到 B 类）

A 类阈值之上自动升级，避免智能管家接太大单出问题。

### 6 步派单流程

```
1. 需求分类（A/B/C）
2. 智能管家池路由（归属优先 → 跨域 → 公开）
3. 4 维加权匹配（地区+业务+等级+评分），Top 3 限时 1h 抢单
4. 报价透明（对照参考价库自动标色：绿/黄/红/超价）
5. 强制双向评分（不评分智能管家分润不结算）
6. 同乾方略接管（6 触发：B/C 类、24h 不响应、报价超 200%、客户主动选、评分差、复杂度标记）
```

### 关键防黑机制

- **报价透明化**：所有候选智能管家报价 + 评分公开展示给客户
- **双向评分闭环**：客户评智能管家强制（不评不结算），智能管家评客户参考用
- **月度淘汰**：均分 < 3★ 暂停 30 天，连续 3 月差进入待清退
- **申诉三级流程**：客服初审 → 风控审核 → 客户成功仲裁
- **黑名单注册防控**：手机号 / 营业执照 / 设备多维度去重

### 同乾方略推荐费结算

```
客户 X 由智能管家 a 推荐 → 进入同乾方略服务货架
   ↓
同乾方略服务订单完成 + 客户验收
   ↓
推荐费进入 "冻结" 状态
   ↓
7 天客户无投诉
   ↓
推荐费转 "可结算"
   ↓
月底统一结算 → 转 "可提现"
   ↓
智能管家申请提现 → 平台审核 → 打款
```

## 6.6 AI 指导边界（防 AI 乱说话毁信誉，详见 ADR-002 §2.8）

平台所有 AI 输出必须按 **4 级 Tier** 分级：

### Tier 1：AI 主动指导（小单 / 日常）

直接给方案，不需要人工复核：

- 合同审查（项目 < ¥1000 万）
- 招标速读、政策解读、催款函、商务函件
- 资质体检（< 一级总包）
- 应收账款分析（< ¥500 万）
- 项目可投性判断（< ¥1000 万）
- 造价粗估、业主资信
- 施工日志、班前会、现场照片
- AI 老板助理对话

### Tier 2：AI 分析 + 建议人工复核（中单）

给分析框架 + 关键提示，报告底部强制 "申请人工复核" 按钮：

- 资质升级（二级 → 一级）
- 标书代写（项目 ¥1000–5000 万）
- 合同审查（项目 ¥1000–5000 万）
- 应收分析（¥500–2000 万）
- 融资诊断（< ¥5000 万授信）
- 项目可投性判断（¥1000–5000 万）
- 资质增项分析

### Tier 3：AI 不给方案，引导咨询（大单）

仅做信息整理 + 风险提示，**不出方案**，必须引导申请同乾方略：

- 资质一级 / 特级升级
- 标书代写（项目 ≥ ¥5000 万）
- 合同审查（项目 ≥ ¥5000 万）
- 应收分析（≥ ¥2000 万）
- 融资规划（≥ ¥5000 万）
- 化债 / ABS / REITs / SPV / 混改
- 政府专项债、央国企融资、重大项目陪标
- PPP / TOT / EOD、跨境投融资

### Tier 4：AI 强制人工接管（极复杂）

AI 拒绝直接给意见，自动跳转人工咨询入口：

- 法律纠纷应对（涉诉案件）
- 重大投诉 / 仲裁
- 多方复杂博弈商务谈判

### AI 输出强制要素

每份报告自动包含：

```
【AI 报告免责声明】
本报告由 AI 生成，仅作为日常参考工具使用，不构成专业法律 / 财务 /
投资意见。重大决策请咨询持牌专业人士或同乾方略团队。

【报告复杂度等级】Tier 1 / 2 / 3 / 4
【AI 信心度】高 / 中 / 低
【建议下一步】
   • Tier 1 → 直接使用
   • Tier 2 → 申请人工复核
   • Tier 3 → 申请同乾方略咨询
   • Tier 4 → 强制人工接管
```

### 关键设计原则

- **AI 不替代专业判断**：禁止用 "必须 / 一定 / 绝对" 等绝对化表述
- **企业先尝试自做**：Tier 2 / 3 任务先引导用户自己消化 AI 整理的内容，再推荐人工
- **不上来就推付费**：避免给用户"上来就被卖"的感觉，让他们觉得 AI 是工具不是销售

## 6.7 信誉机制（智能管家 + 客户双向信誉资产，详见 ADR-002 §2.7）

### 智能管家信誉分（0–1000）

- 基础分 500（新智能管家注册即得）
- 加分：完成订单 +5、5★ 评价 +10、月均 ≥ 4.5★ +30、推荐新智能管家 +50、推荐大单 +100、区域合伙人 +200/年、培训 +20/课、连续月活 12 月 +50
- 减分：差评 -20、投诉成立 -50、超价 -10、不接单 -5、暂停 -100、待清退 -300、违规 -200、黑名单一票否决
- 自然回血：每月活跃 + 无差评 → +20/月

### 智能管家 5 级等级

| 等级 | 信誉分 | 派单加权 | 推荐费上限 | 提现周期 |
|---|---|---|---|---|
| LV1 见习管家 | 0–499 | 公开池末位 | 10% | T+30 |
| LV2 入职管家 | 500–699 | 普通 | 12% | T+15 |
| LV3 资深管家 | 700–849 | +5 | 15% | T+7 |
| LV4 金牌管家 | 850–949 | +10 | 18% | T+3 |
| LV5 首席管家 | 950–1000 | 优先 + 专属客户经理 | 20% | T+0 |

### 客户信誉分（0–1000）

- 基础分 500
- 加分：按时付款 +10、好评 +5、按时评分 +5、连续付费 ≥ 6 月 +50、升档 +30
- 减分：拖延付款 -30、拒不付款 -100、恶意差评 -50、多次退款 -50、薅羊毛 -200
- 联动：< 300 需预付 30% 定金；< 100 暂停派单；≥ 800 显示"优质客户"标识

### 信誉核心设计

- **智能管家信誉对客户公开**（派单时看得到分数 + 等级 + 评价）
- **客户信誉对智能管家选择性公开**（仅接单智能管家可见，防歧视）
- **信誉是智能管家核心动力**：等级越高 → 派单越多 → 推荐费越高 → 提现越快
- **信誉是客户约束**：信誉低 → 需预付定金 → 极低暂停派单
- **申诉机制保护智能管家**：每条扣分可申诉，三级流程公正处理

## 14. 编程相关的关键业务规则

代码层面要重点处理：

### 14.1 阶梯优惠中断重算
- 用户每月续费成功 → counter++
- 任意一月未续费 → counter 重置为 0
- 重新订阅 → counter = 1
- 一次性预付 → 单独标记，独立结算

### 14.2 智能管家分润递延
- 订阅分润不立即给（防退款）
- 客户付费 → 分润进入"冻结"
- 客户用满 7 天无退款 → 分润进入"可结算"
- 月底统一结算 → 进入"可提现"
- 提现申请 → 平台审核 → 打款

### 14.3 退款规则
- 7 天内全额可退（智能管家分润扣回）
- 7–30 天内 50% 可退
- 30 天后不退（除非系统故障）
- 退款必须走审批流（< ¥500 客服自批，> ¥500 财务批）

### 14.4 点数失败退还
- AI 任务预扣点 → 任务失败 → 自动全额退还
- 任务部分完成（如多章节生成完成 3 章失败 1 章）→ 按比例退
- 退还操作必须 idempotent

### 14.5 客户归属保护
- 客户首次注册时绑定智能管家，永久不变
- 智能管家被清退时，客户归属转给"系统"或重新分配
- 智能管家之间不允许"抢客户"

### 14.6 自动续费
- 默认开启，首单页面明确告知
- 用户随时可关闭
- 续费前 7/3/1 天提醒
- 失败重试 3 次（间隔 24h），仍失败转 past_due

### 14.7 阶梯优惠的本质
- 不是"打折"，是"返现"
- 客户付原价 ¥199，到账 ¥199
- 实际享受折扣价（如 ¥179），差价 ¥20 自动充值为点数
- 这样财务流水正常，便于开发票

## 15. 升级与平滑

- 升档：立即生效，按比例补差价
- 降档：当月有效，下月生效
- 退订：当月有效，下月停服
- 重新订阅：30 天内无缝恢复（点数复活），超 30 天作废

## 16. 发票

- 所有付费操作（订阅 / 加购）自动开具电子增值税专用发票
- 月度可下载汇总发票
- 智能管家分润按规定开具劳务费发票

## 18. V4 商业宪法 · 价值优先 / 资源后置

### 3 条不可违反红线

**红线 1**：方案质量 = 100%（不分免费 / 付费）
- 注册 500 点也好，¥999 旗舰也好，每次扣点输出的方案必须达到"如果是律师 / 顾问 / 咨询师做要收 5-10 倍价钱"水平
- 免费用户调用次数有限，但每次输出不打折
- SHALL NOT：故意输出残缺方案诱导找智能管家"补全"

**红线 2**：智能管家定位 = 线下跑腿 + 关系 + 兜底
- 不是 AI 方案的解读员 / 补全员
- AI 已给可执行方案，智能管家职责：跑窗口 / 政府关系 / 临场应对 / 失败赔付
- 客户付服务费 = 省时间 + 出关系 + 兜底，不是再听一遍 AI 已说过的话

**红线 3**：钩子 = 创造价值，不是消耗点数
- 每个钩子若是付费看的内容，客户必须满意
- SHALL NOT：上瘾机制设计成"心理操纵"
- SHALL NOT：钩子输出价值低于点数成本
