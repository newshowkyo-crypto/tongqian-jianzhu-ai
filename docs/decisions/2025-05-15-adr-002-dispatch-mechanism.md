# ADR-002：派单决策与防黑中介机制

**日期**：2025-05-15
**决策人**：项目创始人
**状态**：✅ 已采纳
**前置 ADR**：[ADR-001](./2025-05-15-initial-decisions.md)（启动期决策）

---

## 1. 背景

ADR-001 已经定义了三层服务漏斗（SaaS → 中介派单 → 同乾方略标准咨询 → 同乾方略战略顾问），但当时没有把"客户出现需求时具体派给谁"的决策树写清楚。这是商业逻辑的核心，必须单独成文。

派单逻辑同时承担三个商业目标，相互制衡：

1. **盈利**：把高价值复杂订单留给同乾方略（咨询是利润核心）
2. **裂变**：让中介觉得"在平台有单子接、有得赚"才会拼命推广
3. **品质**：防止黑中介乱报价、薅羊毛、毁掉"同乾方略"品牌

如果派单设计错误，三个目标至少崩一个：
- 同乾方略不接小单 → 派单全归中介 → 高价值单流失
- 同乾方略到处接单 → 中介觉得被薅 → 裂变机制死
- 没有黑中介防控 → 一两次坏服务毁掉品牌

本 ADR 完整定义派单决策树、防黑机制、AI 指导边界。

## 2. 核心决策

### 2.1 派单需求三分类

客户在系统中出现的"需求"先按以下分类：

#### A 类 标准中介服务（派给中介）

由中介承接、平台不抽抽成（仅跨域时收 5%）：

| 服务类型 | 阈值 | 备注 |
|---|---|---|
| 资质代办 | 单笔 < ¥10 万 服务费 | 二级、三级、增项、延期 |
| 标书代写 | 单笔 < ¥3 万 服务费 | 项目金额 < ¥5000 万 |
| 保函撮合 | 全部 | 投标 / 履约 / 预付款 / 质保金 |
| 建企流贷 | 单笔授信 < ¥5000 万 | 银行流贷、应收质押 |
| 农民工保函 | 全部 | 强制要求 |
| 设备融资 | 全部 | 设备租赁 |
| 应收保理 | 单笔 < ¥2000 万 | 商业保理 |

#### B 类 高端 / 复杂服务（同乾方略直接接管，不走中介池）

由同乾方略团队承接，明码标价的"高端服务货架"：

| 服务类型 | 价格区间 | 谁接 | 中介推荐费 |
|---|---|---|---|
| 年度战略顾问 | ¥30–50 万/年 | 同乾方略 | 10–15% |
| 化债策略 | ¥50 万起 | 同乾方略 | 10–15% |
| ABS / ABN / REITs | ¥100 万起 | 同乾方略 | 10–15% |
| 混改 / 并购 / SPV | ¥80 万起 | 同乾方略 | 10–15% |
| 央国企融资规划 | ¥30–100 万 | 同乾方略 | 10–15% |
| 重大项目陪标 | ¥10–30 万 | 同乾方略 | 15–20% |
| 资质一级 / 特级升级方案 | ¥15–30 万 | 同乾方略 | 15% |
| 政府专项债策划 | ¥30 万起 | 同乾方略 | 10–15% |
| PPP / TOT / EOD | 协议定价 | 同乾方略 | 10–15% |
| 跨境投融资 | 协议定价 | 同乾方略 | 10–15% |

#### C 类 灰色地带（标准服务但金额超阈值，自动升级到 B 类）

| 服务类型 | 阈值 |
|---|---|
| 资质代办 | ≥ ¥10 万 → 升级到 B 类 |
| 标书代写 | ≥ ¥3 万 服务费 / 项目金额 ≥ ¥5000 万 → 升级到 B 类 |
| 融资撮合 | 单笔授信 ≥ ¥5000 万 → 升级到 B 类 |
| 应收保理 | 单笔 ≥ ¥2000 万 → 升级到 B 类 |

### 2.2 派单决策树（6 步）

```
客户 X 出现需求 Y
       ↓
┌──────────────────────────────────────────┐
│ Step 1: 需求分类（A/B/C）                 │
│   • A 类 → 进 Step 2 中介池路由           │
│   • B 类 → 直接同乾方略，跳到 Step 6     │
│   • C 类 → 升级为 B 类                   │
└──────────────────────────────────────────┘
       ↓ A 类继续
┌──────────────────────────────────────────┐
│ Step 2: 中介池路由                       │
├──────────────────────────────────────────┤
│ 客户 X 有归属中介 a？                     │
│   ├── 是 → a 业务类型匹配 Y？             │
│   │     ├── 是 → 派给 a（24h 接单窗）    │
│   │     └── 否 → 跨域池（a 拿 5% 介绍费） │
│   └── 否 → 公开池                         │
└──────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────┐
│ Step 3: 跨域 / 公开池 智能匹配（4 维加权）│
├──────────────────────────────────────────┤
│ • 地区匹配（同城+10 / 同省+5 / 跨省+0）   │
│ • 业务子类匹配（精确+10 / 兼容+5）        │
│ • 中介等级（LV5+10 .. LV1+1）             │
│ • 月度满意度（5★+10 / 4★+5 / 3★+0）       │
│                                          │
│ 取总分 Top 3 → 限时 1h 抢单              │
│   ├── 抢到 → 进 Step 4                   │
│   └── 1h 无人抢 → 客服人工派单           │
└──────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────┐
│ Step 4: 报价透明 + 防黑                  │
├──────────────────────────────────────────┤
│ 中介接单时必须填【报价 + 服务说明】       │
│   ↓                                      │
│ 平台对照"市场参考价"自动标色：           │
│   • 报价 ≤ 参考价 100% → 🟢 绿色推荐      │
│   • 100%–150% → 🟡 黄色（提示"高于均价"）│
│   • > 150% → 🔴 红色（推 3 家备选）       │
│   • > 200% → 自动加"换同乾方略"按钮      │
│                                          │
│ 客户可看到所有备选中介的报价 + 评分      │
└──────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────┐
│ Step 5: 服务后强制双向评分                │
├──────────────────────────────────────────┤
│ • 客户给中介评分（1–5★ + 文字评价）       │
│   - 不评分则中介分润不可结算              │
│ • 中介给客户打标签（守信/一般/拖延/拒付）│
│   - 用于该客户后续派单的"客户质量"参考   │
└──────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────┐
│ Step 6: 同乾方略接管的 6 触发              │
├──────────────────────────────────────────┤
│ 触发任一条件订单进同乾方略：              │
│   1. B / C 类需求（直接进入）             │
│   2. 中介 24h 未响应                      │
│   3. 中介报价 > 参考价 200%（客户选择后）│
│   4. 客户主动选"申请同乾方略"             │
│   5. 客户对中介评分 < 3★（重新派单）      │
│   6. 复杂度标记（化债/ABS/REITs/混改等）  │
└──────────────────────────────────────────┘
```

### 2.3 同乾方略推荐费（中介导流到 B 类）

中介推荐的客户最终被同乾方略接走时（B / C 类），中介拿推荐费：

| 服务类型 | 推荐费比例 |
|---|---|
| 重大项目陪标 | 15–20% |
| 资质一级 / 特级升级 | 15% |
| 其他 B 类 | 10–15% |

**结算规则**：
- 同乾方略服务订单完成 + 客户签字验收 → 推荐费进入"冻结"
- 7 天客户无投诉 → 推荐费转"可结算"
- 月底统一结算 → 转"可提现"

### 2.4 双向评分系统

#### 客户评中介（强制）

| 维度 | 描述 |
|---|---|
| 评分时机 | 服务完成后系统强制弹出，不评分中介分润不可结算 |
| 评分内容 | 1–5★ + 文字评价（必填 ≥ 20 字）+ 标签（专业/态度好/价格合理/拖延/乱报价/失联）|
| 月均分 < 3★ | 中介自动暂停派单 30 天 |
| 连续 3 个月 < 3★ | 中介进入"待清退"状态 |
| 单次 1★ 投诉 | 触发客服仲裁 + 平台介入 |

#### 中介评客户（参考用）

| 维度 | 描述 |
|---|---|
| 评分时机 | 服务完成后选填 |
| 评分内容 | 守信 / 一般 / 拖延 / 拒不付款 4 档 + 标签 |
| 用途 | 该客户后续派单时显示给中介参考 |
| 客户被多次"拖延" | 该客户后续派单需预付 30% 定金 |
| 客户被标"拒不付款" | 该客户派单暂停，恢复需客服审核 |

### 2.5 防薅羊毛 / 防黑客机制

#### 注册环节
- 同手机号 / 同身份证 / 同营业执照 = 自动识别为同一实体
- 同 IP + 同设备指纹连续创建 ≥ 3 个账号 → 自动标记 + 风控审核
- 黑名单（手机号 / 营业执照 / 设备）禁止注册

#### 中介环节
- 中介不能用自己手机号 / 关联人手机号注册客户账号（系统检测关联关系）
- 中介使用代理 / VPN / 改 IP 抢单 → 警告（首次）/ 暂停 30 天（再犯）
- 中介账号异地登录 + 异常操作 → 短信验证 + 临时锁定

#### 评分环节
- 同一中介短时间获得大量 5★（≥ 10 条 / 24h，且来自同 IP / 同设备）→ 风控审核 + 评分作废
- 同一中介连续多个 1★（≥ 3 条 / 24h）且评价文字相似 → 风控审核
- 客户恶意差评（被平台仲裁认定 ≥ 3 次失实）→ 警告 + 限制下单

#### 退款环节
- 客户首单后 7 天内退款 → 中介对应分润扣回（已在 BR-201）
- 客户用退款 + 重新注册薅羊毛 → 黑名单
- 同一手机号年内退款 ≥ 3 次 → 限制后续退款（需客服审核）

#### 优惠券 / 奖励
- 邀请奖励上限：每用户 / 每月 5 个邀请，年累计 30 个
- 注册赠送只在首次注册有效（按多维度去重）
- 异常领奖（短时大量领取）→ 自动冻结奖励 + 风控审核

### 2.6 中介申诉机制

中介被暂停 / 待清退后可申诉：

```
中介申诉
   ↓
24h 内客服初审
   ├── 明显误判 → 立即恢复 + 补偿
   ├── 中度争议 → 转风控审核（72h）
   │   ├── 维持原判 → 中介可走客户成功仲裁
   │   └── 改判 → 恢复 + 补偿
   └── 明显违规 → 维持原判 + 公示
```

**重要**：暂停 30 天**不会**自动恢复，必须中介主动申诉 + 客服审核（防躺平）。

### 2.7 信誉机制（中介 + 客户双向信誉资产）

#### 2.7.1 中介信誉分（0–1000）

新中介注册基础分 500，根据持续行为加减。信誉分是中介的**职业资产**，决定派单优先级、推荐费上限、提现周期。

**加分项：**

| 行为 | 加分 |
|---|---|
| 完成订单（客户验收）| +5 |
| 客户 5★ 评价 | +10 |
| 月度均分 ≥ 4.5★ | +30 |
| 成功推荐新中介（新中介首笔结算后）| +50 |
| 推荐客户被同乾方略接走 B 类大单 | +100 |
| 升级为区域合伙人 | +200/年 |
| 完成中介学院培训课程 | +20/课 |
| 连续 12 月月活 | +50 |

**减分项：**

| 行为 | 减分 |
|---|---|
| 服务被差评（< 3★）| -20/次 |
| 客户投诉经平台仲裁成立 | -50 |
| 报价超参考价 200% | -10/次 |
| 24h 不接单（已派的）| -5/次 |
| 被暂停 30 天 | -100 |
| 进入"待清退" | -300 |
| 风控审核违规 | -200 |
| 黑名单（薅羊毛 / 串标 / 严重违规）| 一票否决归零并封号 |

**自然回血**：每月活跃 + 无差评 → +20/月（每月最多 +20，不超过当前等级上限）。

#### 2.7.2 中介 5 级等级

信誉分自动决定中介等级：

| 等级 | 信誉分 | 派单加权 | 推荐费上限 | 提现周期 |
|---|---|---|---|---|
| LV1 新手 | 0–499 | 公开池末位 | 10% | T+30 |
| LV2 见习 | 500–699 | 普通（基线）| 12% | T+15 |
| LV3 熟练 | 700–849 | +5 | 15% | T+7 |
| LV4 金牌 | 850–949 | +10 | 18% | T+3 |
| LV5 钻石 | 950–1000 | 优先派单 + 专属客户经理 | 20% | T+0 |

**约束**：
- LV3 以下中介接 B 类推荐费仅按 10% 计算（不享 15–20% 上限）
- LV5 中介月度自动获得"钻石中介"标识，公开展示给客户
- 等级升降级实时计算，但生效有 24h 缓冲（防短期波动）

#### 2.7.3 客户信誉分（0–1000）

客户基础分 500，影响后续派单的"客户质量"参考：

**加分项**：按时付款 +10/单、给中介好评 +5/次、按时评分 +5/次、连续付费 ≥ 6 月 +50、升级订阅档位 +30

**减分项**：拖延付款 -30/次、拒不付款 -100、恶意差评（仲裁认定）-50、年内退款 ≥ 3 次 -50/次、薅羊毛行为 -200、黑名单 → 永久封号

**联动规则**：
- 客户信誉 < 300 → 后续派单需预付 30% 定金
- 客户信誉 < 100 → 暂停派单，恢复需客服审核
- 客户信誉 ≥ 800 → 派单时显示"优质客户"标识

#### 2.7.4 信誉公开度

| 角色 | 可见内容 |
|---|---|
| 客户（派单时）| 候选中介的：分数 + 等级 + 评价摘要 + 近 30 天差评数 |
| 中介（接单后）| 该客户的信誉分 + 等级 + 客户标签（防老赖） |
| 平台运营 | 全部可见，含变动明细 |
| 中介自己 | 自己分数、变动历史、申诉入口；**SHALL NOT** 看到加减分公式细节（防刷分） |

#### 2.7.5 信誉申诉

中介对每条扣分项可在 7 天内申诉，按 BR-314 三级流程：客服初审 24h → 风控审核 72h → 客户成功仲裁。申诉成立 → 加回原扣分 + 平台公开纠正。

#### 2.7.6 信誉与派单联动（覆盖 §2.2 Step 3 旧权重）

派单 4 维加权评分中，**中介等级权重提升为最大**：

| 维度 | 加分 |
|---|---|
| 地区匹配 | 同城 +10 / 同省 +5 / 跨省 +0 |
| 业务子类匹配 | 精确 +10 / 兼容 +5 |
| **中介等级** | **LV5 +20 / LV4 +15 / LV3 +10 / LV2 +5 / LV1 +1** |
| 月度满意度 | 5★ +10 / 4★ +5 / 3★ +0 |

让信誉分成为中介核心动力。

### 2.8 AI 指导边界（防止 AI 乱说话毁信誉）

AI 在不同复杂度任务上的行为约束：

#### Tier 1：AI 可主动指导（小单 / 日常）

AI 给出明确建议、可执行方案，无需人工复核：

- 合同审查（项目金额 < ¥1000 万）
- 招标速读（任何金额，仅信息整理）
- 资质体检（< 一级总包）
- 催款函 / 商务函件
- 政策解读 / 行业资讯
- 施工日志 / 班前会记录 / 现场照片
- 应收账款分析（< ¥500 万）
- 项目可投性判断（< ¥1000 万）
- 造价粗估
- 业主资信查询
- AI 老板助理对话

#### Tier 2：AI 可分析但必须提示"建议人工复核"

AI 给出分析框架 + 关键提示，但报告底部强制有"申请人工复核"按钮：

- 资质升级方案（二级 → 一级）
- 标书代写（项目金额 ¥1000–5000 万）
- 合同审查（项目金额 ¥1000–5000 万）
- 应收账款分析（¥500–2000 万）
- 融资可能性诊断（授信 < ¥5000 万）
- 项目可投性判断（¥1000–5000 万）
- 资质增项分析

#### Tier 3：AI 不主动给方案，只推送"申请人工咨询"

AI 仅做信息整理 + 风险提示，**不出方案**，必须引导到同乾方略：

- 资质一级 / 特级升级
- 标书代写（项目金额 ≥ ¥5000 万）
- 合同审查（项目金额 ≥ ¥5000 万）
- 应收账款分析（≥ ¥2000 万）
- 融资规划（授信 ≥ ¥5000 万）
- 化债 / ABS / ABN / REITs / SPV / 混改
- 政府专项债策划
- 央国企融资规划
- 重大项目陪标
- PPP / TOT / EOD
- 跨境投融资

#### Tier 4：AI 完全不输出（强制人工接管）

AI 拒绝直接给意见，自动跳转人工咨询入口：

- 法律纠纷应对（涉诉案件）
- 重大投诉 / 仲裁
- 涉及多方复杂博弈的商务谈判

### 2.9 AI 输出强制要素

每份 AI 报告必须包含：

```
【AI 报告免责声明】
本报告由 AI 生成，仅作为日常参考工具使用，不构成专业法律 / 财务 /
投资意见。重大决策请咨询持牌专业人士或同乾方略团队。

【报告复杂度等级】Tier 1 / Tier 2 / Tier 3
【AI 信心度】高 / 中 / 低
【建议下一步】（自动选）
   • 直接使用（Tier 1）
   • 申请人工复核（Tier 2）
   • 申请同乾方略咨询（Tier 3 / 4）
```

## 3. 影响

### 3.1 对代码的影响

新增 5 个核心模块：
- `apps/api/src/modules/dispatch/`（派单引擎）
- `apps/api/src/modules/rating/`（双向评分）
- `apps/api/src/modules/reputation/`（**信誉机制 - 中介 + 客户**）

- `apps/api/src/modules/ref-price/`（市场参考价库）
