## 核心决策（不可再改）

### 1. 商业宪法 V4 · 价值优先 / 资源后置

```
任何 AI 输出必须遵守 3 条不可违反红线：

红线 1：方案质量 = 100%（不分免费 / 付费）
   • 注册免费 500 点也好，¥999 旗舰也好，每次扣点输出的方案
     必须达到"如果是律师 / 顾问 / 咨询师做要收 5-10 倍价钱"水平
   • 免费用户调用次数有限，但每次输出不打折
   • SHALL NOT：故意输出残缺方案诱导找智能管家"补全"

红线 2：智能管家定位 = "线下跑腿 + 关系 + 兜底"
   • 不是 AI 方案的解读员 / 补全员
   • AI 已给可执行方案，智能管家职责：
     ① 替客户跑窗口 / 排队 / 盖章
     ② 联系业主 / 评审 / 政府关系
     ③ 处理材料齐备 / 现场答辩 / 应急
     ④ 失败赔付 + 临时调度
   • 客户付的服务费是"省时间 + 出关系 + 兜底"
     不是"再听一遍 AI 已说过的话"

红线 3：钩子 / 上瘾机制 = 让客户多用平台来创造价值
   • 每个钩子若是付费看的内容，客户必须满意
   • SHALL NOT：钩子只为消耗点数，输出价值低于点数成本
   • SHALL NOT：上瘾机制设计成"心理操纵"
```

### 5. 派单 3 流程（最终版）

```
A 流程·标准派单（占 60%）
   归属智能管家优先（业务子类匹配）
   24h 不接 → 跨域池（5% 介绍费）
   1h 不抢 → 公开池（4 维加权）
   1h 不抢 → 客服兜底

B 流程·智能管家主动捞单
   AI 客户预警卡 → 主动联系 → 引导客户在 AI 报告点"申请管家"
   → 进 A 流程归属优先

C 流程·同乾方略接管（占 10%）
   触发：Tier 3/4、≥¥5000 万、化债类、客户主动选、24h 不响应、
        报价超 200%、评分 < 3★
   → 归属智能管家拿 10-15% 推荐费
```

### 6. 4 大防黑机制

```
机制 1：AI 不和智能管家抢饭碗
   - AI 报告底部 100% 出现"如需人工执行可申请智能管家服务"
   - 续证 / 升级类报告必须含"建议联系智能管家"

机制 2：智能管家不和同乾方略抢饭碗
   - 智能管家工作台不展示 B 类接单按钮
   - 检测到 B 类需求 → 主动引导上报 → 拿推荐费 10-15%
   - 私接 B 类 → 扣信誉 -300 + 黑名单

机制 3：归属智能管家保护 + 客户保护
   - 24h 不响应 → 转跨域（拿 5% 介绍费）
   - 30 天月活 < 30% → 客户可申请换管家
   - 90 天月活 < 10% → 待清退

机制 4：客户绕单防控
   - 月外联次数 ≤ 5 次 / 月
   - 系统检测"加微信""线下" → 弹窗提醒
   - 私接被发现 → 终身封禁
```
