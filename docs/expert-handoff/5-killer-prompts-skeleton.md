# 5 大 Killer Prompt 骨架

## 1. contract-review-pro

用途：合同风险审查。

专家需补：

- 常见条款风险库
- 建筑施工合同特殊风险
- 付款、工期、违约、签证、结算审查标准
- 老板版行动清单

## 2. tender-framework-pro

用途：投标框架与标书策略。

专家需补：

- 评分点拆解
- 响应偏离表
- 商务/技术/资信策略
- 废标风险提示

## 3. qualification-upgrade-pro

用途：资质升级与维护。

专家需补：

- 资质条件清单
- 人员、业绩、社保、设备材料
- 时间线
- 失败兜底方案

## 4. policy-fund-match

用途：政策资金匹配。

专家需补：

- 申报条件判断
- 材料清单
- 成功率评分
- 政企沟通注意事项

## 5. morning-briefing

用途：老板 90 秒早报。

专家需补：

- 5 条干货结构
- 本省政策/机会/风险/同行/数据模板
- 禁止空话规则
- 点数价值说明

## 通用输出必须包含

- 免责声明
- Tier 徽章
- AI 信心度
- 角色裁剪按钮
- 数据来源

由 Codex 自动生成 + 创始人 / 律师 / 专家审核
