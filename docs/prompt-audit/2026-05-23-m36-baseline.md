## Not Adopted

- No AGPL or repository source code was copied from OpenConstructionERP or other projects.
- Heavy workflow stacks such as n8n, Qdrant and BIM/CAD runtime dependencies were not adopted in M36.
- Generic multi-agent frameworks were not adopted because current value is in Chinese construction prompt precision, tenant audit, credits and admin review.
- Foreign legal patterns were only kept as FIDIC edge-case guidance for foreign-related contracts, not as default China-local advice.
