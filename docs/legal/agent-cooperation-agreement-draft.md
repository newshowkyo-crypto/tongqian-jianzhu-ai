# 智能管家合作协议草案

## 合作定位

智能管家提供线下跑腿、窗口沟通、关系协调、现场兜底服务，不是 AI 方案补全员。

## 五项强制承诺

1. 承诺合规用工，不参与挂证或假社保。
2. 承诺真实业绩，不参与材料作假。
3. 承诺平台内交易，不绕单。
4. 承诺保护客户隐私。
5. 承诺接受信誉投诉裁决。

## 禁止行为

- 私下收款。
- 泄露客户资料。
- 虚假承诺通过率。
- 冒用平台名义。
- 参与违法资质操作。

## 收益与结算

- 平台按规则结算。
- 涉现金奖励按税法代扣代缴。
- 异常订单可冻结。

## 违约处理

- 立即清退。
- 信誉一票否决。
- 全网黑名单。
- 追偿损失。

## 律师必审条款

- 劳务/合作关系边界。
- 竞业与排他是否合规。
- 佣金结算税务。
- 投诉仲裁流程。
