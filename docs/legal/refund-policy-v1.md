# 同乾方略 · 退款政策 V1

生效状态：草案  
关联规则：BR-104 退款与服务补偿规则

## 1. 适用范围

本政策适用于订阅费、点数充值、AI 报告扣点、智能管家服务费、同乾方略咨询预约金或其他平台公示的付费项目。

## 2. 退款原则

1. 已实际消耗的点数原则上不退，但因系统错误、重复扣点、报告生成失败可退回点数。
2. 免费赠送点数、活动权益、优惠券不折现退款。
3. 订阅退款按已使用周期、已享权益、发票税费和渠道手续费综合计算。
4. 智能管家和咨询服务退款需结合交付进度、责任归属和客户确认记录处理。

## 3. 可退款场景

1. 平台系统故障导致服务未交付且无法补交付。
2. 重复支付、误充值且点数未使用。
3. AI 报告因平台原因生成失败或内容为空。
4. 经平台确认的重大交付违约、投诉成立或服务质量严重不达标。

## 4. 不予退款场景

1. 用户已完整使用服务后仅因主观不满意申请退款，且平台无明显违约。
2. 用户上传资料错误、缺失、虚假或无权处理导致报告不可用。
3. 用户未按 Tier 建议进行人工复核，擅自执行导致损失。
4. 用户违反协议、绕开平台交易、恶意投诉或滥用退款机制。

## 5. 退款流程

1. 用户提交退款申请并说明订单、金额、原因和证据。
2. 平台在 3 个工作日内初审，复杂事项可延长至 10 个工作日。
3. 涉及智能管家的，平台同步冻结争议分润并启动责任认定。
4. 退款通过原支付路径退回；无法原路退回的，按平台客服确认方式处理。

## 6. 分润扣回

若退款与智能管家交付责任相关，平台可按责任比例扣回对应分润；已提现部分可从后续结算中抵扣或依法追偿。

## 7. 律师重点审核

请律师重点审核：消费者权益适用、企业客户退款限制、自动续费、预付费监管、发票处理、点数性质、退款时限、争议举证责任。
