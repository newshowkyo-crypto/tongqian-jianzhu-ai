## ⚙️ 标准工作流(每张海报都按这个跑)

```
Step 1 · 生成器选择
  ✅ 首选:Ideogram 3.0(中文文字最准)
  备选:GPT-Image-1(整体构图最强,但中文易缺笔)

Step 2 · 跑 6-8 张挑 1 张
  同 prompt 跑多次,挑文字最准的版本(允许 80% 文字对)

Step 3 · PS 文字层 100% 校正(必做)
  所有中文用 PS 文字层重打覆盖,确保 100% 准确
  - 标题:思源宋体 Heavy
  - 副标:思源黑体 Heavy
  - 正文:思源黑体 Regular
  - 英文:Inter Light caps

Step 4 · 颜色精校
  - 暖金统一 #d4953a / 高光金 #f4c46b
  - 深蓝渐变 #061029 → #0a1c3a → #050b1a
  - cyan 蓝 #4da6ff / violet 紫 #7b6cff

Step 5 · 印刷分辨率
  Topaz Photo AI 或 Magnific 放大到 4K(印刷级 2048×2730)

Step 6 · 二维码替换
  QR 占位区贴上真实二维码
  - 公众号 / 视频号 / 抖音 / 百家号 / 知乎 / 头条 / 快手
  - 企业微信:商务团队
```

## 🚫 通用红线(所有海报禁止出现)

```
❌ NO 3D 水晶玻璃发光球图标 → 用极简铜金线性图标(Lucide/Feather)
❌ NO 整图覆盖式粒子风暴 → 仅 2 条对称弧光 + 4 角少量金粉
❌ NO 卡通形象 / 吉祥物
❌ NO 鲜艳消费色 红/橙/粉/紫(作为主色)
❌ NO emoji 当功能图标(emoji 仅作 prompt 占位提示)
❌ NO "中介"二字(必用"智能管家")
❌ NO 倒计时器 / 限时大促 banner
❌ NO 模糊或残缺的中文字符
❌ NO 过饱和彩虹渐变
❌ NO 老气死板的企业风
❌ NO 地摊广告感
```
